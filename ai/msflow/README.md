# MSFlow (generation code only)

The text-to-motion model behind Studio's **Describe a motion**: MotionSpaceFlow (MSFlow) by
Qing Yu and Kent Fujiwara, LY Corporation. Source: https://github.com/yu1ut/MSFlow (CC0 1.0, see
`LICENSE.txt` and `NOTICE.txt`), copied unchanged; training, evaluation and demo files are left out.

The pretrained weights (`MMDiT_xyz_pretrained`, Apache-2.0) and the DistilBERT text encoder
(Apache-2.0) are not stored here: `ai/setup_ai.ps1` downloads them from Hugging Face into `ai/models/`.
